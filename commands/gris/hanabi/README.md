# hanabi

ターミナルに打ち上げ花火を上げる。
夜景のビル群の向こうに、5 種類の玉がランダムに打ち上がって咲く。
ANSI エスケープコード（truecolor）と `setInterval` だけで実装。

| 玉 | 特徴 |
| --- | --- |
| 菊 | 尾を引いて球状に広がる。最後にパチパチ瞬くことも |
| 牡丹 | 尾を引かないくっきりした光の点。二重の輪 |
| 柳 | 金色の長い尾が重く垂れ下がる |
| 千輪 | 小さな花がいくつも遅れて咲く |
| ハート | 型物。たまに上がる |

## 使い方

```bash
python lab.py gris hanabi
```

| キー | 動作 |
| --- | --- |
| `space` | 1 発打ち上げ |
| `f` | スターマイン（連続打ち上げ） |
| `h` | ハートを打ち上げ |
| `q` / `Esc` / `Ctrl+C` | 終了 |

何もしなくても自動で打ち上がり続ける。ターミナルのウィンドウサイズに自動対応。

## 依存

なし（Node.js 標準ライブラリのみ）。
