# botw — Bloom of the Wisper（開花のささやき）

禍々しい影が大地を蝕んでいる。火山、空の島、砂漠、水の都 — 四つの守護獣を越えた者だけが、影の座に挑むことができる。

## 起動方法

```bash
python lab.py mona botw
```

または直接：

```bash
cd commands/mona/botw
node index.js
```

## ゲーム概要

- 勇者の名前を入力して冒険開始
- 4つのエリア（火山・空の島・砂漠・水の都）を移動しながら敵と戦い、レベルアップ
- ラスボス「ガノンドロス」を倒すとエンディング

## マップ

```
[影の座]    ← ガノンドロスがいる
   │
[水の都]    ← ゾウの敵が出る
   │
[砂漠]      ← ラクダの敵が出る
   │
[空の島]    ← 鳥の敵が出る
   │
[火山]      ← トカゲの敵が出る
   │
[村ルーメ]  ← みせ・やどがある（セーフゾーン）
```

## コマンド（フィールド）

| コマンド | 効果             |
|----------|------------------|
| `n`      | 北（先）へ移動   |
| `s`      | 南（村側）へ移動 |
| `s`      | みせ（村のみ）   |
| `i`      | やど（村のみ）   |
| `st`     | ステータス表示   |
| `save`   | セーブ           |
| `load`   | ロード           |
| `map`    | マップ表示       |
| `q`      | ゲーム終了       |

## コマンド（戦闘）

| コマンド | 効果                                     |
|----------|------------------------------------------|
| `1`      | 剣で攻撃（物理攻撃）                     |
| `2`      | 弓で攻撃（防御力を貫きやすいがやや低威力）|
| `3`      | りんごで回復（HP 35〜45 回復）           |
| `4`      | 回避（次の敵の攻撃を確実にかわす）       |

## 成長システム

- Lv.1〜12 まで成長
- 敵を倒すと経験値とゴールドを獲得
- レベルアップ時：HP・MP・攻撃力・防御力が上昇
- ガノンドロス攻略推奨レベル：Lv.10〜12

## セーブデータ

`commands/mona/botw/save.json` に保存されます。
タイトル画面の `[l]つづきから` か、フィールドで `load` コマンドで読み込めます。

## 動作環境

- Node.js 18 以上
- 外部依存なし（標準ライブラリのみ）
- ANSI カラー対応ターミナル推奨

## 演出

- タイプライター風テキスト表示
- ブロックフォント（BLOOM / WISPER）のタイトル画面
- ANSI カラー（黄・白・赤・緑・青・紫）
- 枠付きメッセージ（戦闘開始・レベルアップ・ゲームオーバー・エンディング）
