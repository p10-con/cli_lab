# sodateru — 育てる（実時間で育つ観葉植物ビューア）

植えた瞬間から時間が進み、25分かけて満開（成熟）まで育つ観葉植物のアンビエントトイ。閉じても時間は進むので、ふと開いたときにどれだけ育ったかを眺めて楽しむ。

## 起動方法

```bash
python3 lab.py mona plant
```

または直接：

```bash
cd commands/mona/plant
node index.js
```

## 使い方

初回起動時に育てる植物を選ぶ。以降は起動すると自動で「ライブ観察モード」に入り、成長度が再描画される。

```
どの植物を育てますか？
  [1] ビカクシダ
  [2] オリーブ
  [3] フィカス
  [4] シェフレラ
  [5] パキラ
```

| コマンド | 効果                                   |
|----------|----------------------------------------|
| `q`      | 終了                                    |
| `r`      | 植えかえる（確認後、成長がリセットされる）|

## 成長の仕組み

- 「植えた時刻」からの経過時間（実時間）だけを保存し、起動ごとに `経過時間 ÷ 25分` で成長度（0〜100%）を計算する
- アプリを閉じていても時間は進む。次に開いたときに続きの成長度が表示される
- 6段階（種 → 発芽 → 若葉 → 生長中 → 葉が茂る → 立派に成熟）で見た目が変化し、6時間で満開になる

## セーブデータ

`commands/mona/sodateru/save.json` に「選んだ植物」と「植えた時刻」だけが保存される。

## 動作環境

- Node.js 18 以上
- 外部依存なし（標準ライブラリのみ）
- ANSI カラー対応ターミナル推奨
